# 🧮 Simple Calculator Using Python Tkinter

## 📌 About the Project

This is a simple calculator application built using **Python and Tkinter**. It provides a graphical user interface (GUI) with buttons to perform basic mathematical calculations.

The calculator is easy to use and suitable for Python beginners who want to learn GUI development.

## ✨ Features

* Simple and user-friendly interface.
* Performs basic mathematical operations.
* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)
* Clear button (C) to clear the input.
* Equals button (=) to display the result.
* Built using Python's Tkinter library.

## 🛠️ Technologies Used

* **Python**
* **Tkinter** (GUI library)

## 📂 Project Structure

```text
Calculator/
│
└── calculator.py
```

## ⚙️ Requirements

* Python 3 installed on your computer.
* Tkinter (usually included with Python).

## 🚀 How to Run the Project

**Step 1:** Clone the repository.

```bash
git clone YOUR_REPOSITORY_URL
```

**Step 2:** Open the project folder.

```bash
cd Calculator
```

**Step 3:** Run the Python file.

```bash
python calculator.py
```

A calculator window will open on your screen.

## 🖥️ How to Use

1. Run the Python program.
2. Click the number buttons to enter a calculation.
3. Click an operator (+, -, *, /).
4. Click `=` to see the result.
5. Click `C` to clear the display and start again.
